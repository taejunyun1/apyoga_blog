| 채널 로고 | Naver/Instagram 브랜드 아이콘 | 텍스트 탭 | 외부 브랜드 자산 미번들, 기능은 동일 |

## 최종 QA 결과

- 390×844: 가로 넘침 없음, 하단 상태 레일 표시, 콘솔 오류·경고 없음
- 1280×900: 760px 중앙 컬럼, 가로 넘침 없음, 콘솔 오류·경고 없음
- 결과 화면: 채널 탭, 후보 그룹, 편집, 검수, 복사 순서 유지
- `prefers-reduced-motion`에서는 전환 규칙이 적용되지 않아 즉시 반응
- 생성형 콘셉트의 장식 요소보다 실제 문서의 P0 기능과 개인정보 원칙을 우선함
